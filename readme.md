# Canvas Holidays — St. Martin booking website (PHP)

PHP + MySQL (or SQLite) site with an admin panel. Requires PHP 8.0+ with PDO.

## Install
1. Upload all files to your hosting (document root or a subfolder).
2. Create an empty MySQL database (or choose SQLite in the installer).
3. Open `/install.php`, enter DB details and the admin username/password.
4. **Delete `install.php`** after installation.
5. Log in at `/admin/login.php`.

## Admin panel
- **সাইট সেটিংস** — logo, favicon, site name, phone, WhatsApp, address, map, social links, hero text, notice, section titles, footer, SEO.
- **সীপ / প্যাকেজ / কেন আমরা / ধাপ / FAQ** — add, edit, reorder, hide, delete.
- **বুকিং** — inquiries submitted from the form (also opened in WhatsApp); set status or delete.

## Notes
- `config.php` (DB credentials) is generated by the installer and git-ignored.
- `uploads/` holds the logo/favicon; PHP execution is disabled there via `.htaccess` (Apache). On Nginx, deny PHP in `uploads/` and block `includes/` and `config.php`.
- With SQLite, keep the generated `data-*.sqlite` file out of public access (Apache `.htaccess` blocks it; on Nginx add a deny rule).
